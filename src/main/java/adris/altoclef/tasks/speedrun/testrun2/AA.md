# @aa — All Advancements (1.16.1 through 26.x)

```
@aa
```

Catalog covers every Java gameplay ID from 1.16.1 up through the 2026 drops. `McCompat.gameMinor()` reads `1.16`–`1.21` and the new `26.x` calendar versions. IDs newer than the client, or whose item field is missing, are skipped.

| Client | Extra IDs beyond 1.16 |
|---|---|
| 1.17 | goat boat, wax, axolotl, glow sign, spyglass ×3, powder snow |
| 1.18 | Caves & Cliffs fall, Feels Like Home, Sound of Music, Star Trader |
| 1.19 | allay, tadpole, froglights, frogs, sculk, Sneak 100 |
| 1.20 | archaeology, sniffer, armor trims |
| 1.21 / 1.21.1 | trial chambers, vaults, mace, breeze, armadillo, wolf armor |
| 1.21.6+ | Stay Hydrated (`husbandry/place_dried_ghast_in_water`), Heart Transplanter (`adventure/heart_transplanter`) |
| 1.21.11 Mounts of Mayhem | Mob Kabob (`adventure/mob_kabob`) |
| 26.2 Chaos Cubed | Uh Oh (`husbandry/uh_oh` — TNT into a sulfur cube) |
| 26.3 Wilderness Bound | no new ID (dappled forest only expands Adventuring Time) |

On 1.16.5 you still only walk the original ~80. On a 26.2 client you get Uh Oh after the 1.21 block.

`new AaCommand()` next to `new Testrun2Command()`.
